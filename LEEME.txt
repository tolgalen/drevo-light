Drevo Light 1.1 - Tyrfing V2   (interfaz PySide6 / Qt, licencia GPL v3 o posterior)

EJECUTAR
  Linux:   ./run.sh      (necesita python3-venv; la primera vez instala PySide6 y hidapi)
  Windows: doble clic en run.bat (Python 3.9+; la primera vez crea .venv e instala las dependencias)

PERMISOS (Linux)
  Opcion A: Archivo > Instalar reglas udev (Linux)...  desde la propia aplicacion.
  Opcion B: packaging/install_linux.sh   (menu de aplicaciones + regla udev)
  Opcion C: sudo install -m 644 99-drevo-tyrfing.rules /etc/udev/rules.d/ && sudo udevadm control --reload && sudo udevadm trigger

MANUAL
  Ayuda > Manual de usuario (F1): se puede imprimir o guardar en PDF.

ESTRUCTURA
  drevo_light.py        lanzador
  drevolight/           codigo: proto.py (protocolo del teclado), core.py, state.py (deshacer),
                        window.py, keyboard_view.py, dialogs.py, worker.py ...
  lang/                 un XML por idioma + manual_xx.html (anade un idioma copiando en.xml)
  assets/               icono, iconos Lucide (SVG)
  packaging/            PyInstaller (Linux/Windows), instalador Inno Setup, entrada de menu .desktop
  tests/                pruebas automaticas:  pip install -r requirements-dev.txt && pytest

AJUSTES Y PERFILES
  Linux ~/.config/drevo-light/   Windows %APPDATA%\drevo-light\   (settings.json, profiles.json)
  Los ficheros ~/.drevo_light*.json de la version 1.0 se copian automaticamente.
