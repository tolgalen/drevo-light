Drevo Light — User manual

Drevo Light controls the lighting of the Drevo Tyrfing V2 keyboard (USB 0416:a0f8): per-key colors, key-group colors and effects. This manual explains every part of the application.

1. Getting started

  • Connect the keyboard by USB. The Keyboard status panel (top) shows whether it is detected: green dot = connected with access, yellow = detected but no access, red = not detected.
  • On Linux, copy 70-drevo-tyrfing.rules to /etc/udev/rules.d/ and run sudo udevadm control --reload && sudo udevadm trigger to get access permissions.
  • You can also use File → Install udev rules (Linux)…, which installs them asking for the administrator password.
  • Close the official Drevo software: it uses the same channel and blocks access.
  • Interface: Automatic is usually enough. USB diagnostics lists the detected HID interfaces in case you need to pick another one.

2. The window

  • Menu bar: File, Profiles, Theme, Language and Help. The keyboard size (for example “TKL 88 KEYS”) is shown on the right.
  • Keyboard status: connection, last command, interface selector and the Re-detect, USB diagnostics and Check now buttons.
  • Sidebar: the three work pages — Keyboard, Colors and Effects.
  • Footer: status messages for the last action.

3. Keyboard page (visual editor)

This is the main editor. It shows a keyboard where you pick keys and paint them. What you see is a preview: nothing reaches the real keyboard until you press Apply to keyboard. On startup the editor begins from an unlit keyboard.

Layout and size

Choose the layout (US ANSI; UK, ES, DE, FR and IT in ISO) and the size (TKL or Full size). Only the drawing and legends change: colors are stored by each key's physical position, so they are kept when you switch layouts.

Selecting keys

  • Click a key: selects it or removes it from the selection.
  • Drag: draws a rectangle and adds every key it touches to the selection. Drag several times to accumulate several areas.
  • Ctrl + drag: toggles the keys in the area (removes the selected ones, adds the rest).
  • Shift + drag or click: replaces the selection with the new one.
  • Click the background: clears the selection. Ctrl+A selects all keys.
  • Buttons All, None, Invert and the group buttons (Letters, Digits, F keys, Modifiers, Editing, Arrows).

Painting

Pick a color with the color box and press Paint selection, or press one of the preset colors (they paint directly). Clear color returns the selected keys to the base color.

Sending to the keyboard and clearing

  • Apply to keyboard: sends the base color, the groups and the individual keys.
  • Lights off: turns all lighting off.
  • Reset keyboard: clears the editor and turns the keyboard lighting off (asks for confirmation).
  • Clear editor: removes all selections and colors from the editor, without touching the real keyboard.

4. Colors page

  • 1. Whole keyboard color: base color for keys with no other color.
  • 2. Colors by key group: tick a group (Letters, Digits, F keys…) and choose its color.
  • 3. Individual keys: type the key name (esc, space, enter, w, f5…), choose a color and press Add. The table lists the colored keys; Remove deletes the selected ones.
  • Apply colors sends everything to the keyboard. Priority: individual key > group > base color.

5. Effects page

Effects are stored in the keyboard itself and stay active after you close the application. Choose the effect (Static, Breathing, Radar, Stream, Memory), colors 1 and 2, brightness, speed, rainbow and direction (Stream only), then press Apply effect. To go back to per-key colors use Apply to keyboard.

6. Advanced editing

  • Undo / Redo (Edit menu): every color change can be undone, including “Clear editor”. The window title shows an asterisk (*) when there are changes not saved to a profile.
  • Copy and paste color: copy the color of the first selected key and paste it onto other keys.
  • Gradient…: fills the selection with a two-color blend or a rainbow, horizontally or vertically.
  • Recent: the last colors used appear as swatches; press one to paint the selection. The color dialog also keeps your “custom colors” between sessions.
  • Rows: the numbered buttons select a whole keyboard row.
  • Live apply: with this box ticked every change is sent to the keyboard automatically, without pressing “Apply to keyboard”.
  • Add selection (Colors page) adds the selected keys with the chosen color; the name field autocompletes and warns if the key does not exist.
  • Commands are sent to the keyboard in the background: the window never freezes even if USB is slow.

7. Profiles

  • The Profiles menu offers 20 slots. Choosing a named slot loads that profile into the editor; it is not sent to the keyboard until you press “Apply to keyboard”.
  • Save current profile in… lets you pick a slot and a name (it asks for confirmation if you overwrite).
  • Rename and Delete work on slots that hold a profile.
  • Import from file… and Export to file… use .json files to move profiles to another computer.
  • A profile stores the colors (base, enabled groups and individual keys), the effect settings, the last applied mode (colors or effect) and the keyboard layout; it does not store the theme or the language. They are saved in ~/.config/drevo-light/profiles.json.
  • Manage profiles… opens a window with the 20 slots and a thumbnail of each profile (double-click to load it).
  • The options Apply to keyboard when loading a profile and Apply the last profile at startup send the profile to the keyboard automatically.
  • If the editor has unsaved changes, the application asks before replacing them when you load or import a profile.

8. Theme and language

The Theme menu offers System, Light, Dark, Dark blue and Drevo. The Language menu offers Español, English, Français, Italiano, Deutsch and Português. Both are remembered between sessions. To add a language, copy lang/en.xml to lang/xx.xml and translate it.

9. Troubleshooting

  • Keyboard NOT detected: check the USB cable and close the official Drevo software.
  • Detected, but no access: on Linux the udev permissions are missing (see “Getting started”); on any system, close the official software.
  • Error when applying: open USB diagnostics, pick another interface in the “Interface” selector and try again.
  • The color does not match: the preview is approximate; the real brightness depends on the keyboard.

10. Keyboard shortcuts

  • Ctrl+A: select all keys.
  • Ctrl+Z / Ctrl+Y: undo / redo.
  • Ctrl+C / Ctrl+V: copy / paste the color of the selected keys.
  • F1: open this manual.
  • Ctrl+Q: quit.
